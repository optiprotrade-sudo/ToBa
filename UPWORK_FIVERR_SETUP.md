# ToBa: Upwork + Fiverr account setup

**Suggested public business brand:** ToBa (working name; availability and trademarks not verified).  
**Upwork profile/account name:** use your genuine personal name, not the studio brand. The name you use publicly should be a name you use in everyday life; verification and payout details must be accurate.  
**Fiverr display name:** use a name that represents you, such as your first name or first name + last initial, according to Fiverr's rules. You can put the studio brand in the work samples and branding.  
**Potential Fiverr username:** `tobadevworks` if Fiverr permits it and it is available. Fiverr usernames are permanent, so check before registering.

## 1. Upwork – https://www.upwork.com/

1. Click **Sign Up**, register with your own email or Google login, and select to **work as a freelancer** if asked. Use a strong unique password and turn on account security features.
2. Enter truthful personal information and Nigeria as your actual country. Complete the email and any phone verification prompted.
3. Profile headline: **Web Developer | Responsive Websites, Dashboards & Bug Fixes**.
4. Specialty: web development (choose the closest available category). List skills you can personally deliver: HTML, CSS, JavaScript, responsive design, website bug fixing, dashboard interfaces, deployment support.
5. Starter rate suggestion: **$15/hour** (not a guaranteed achievable market price). Adjust after reviewing comparable work and delivery effort.
6. Write your overview (below), add a recent professional photo, and upload portfolio samples or links to original projects you are allowed to display.
7. Complete any requested identity and tax/payment verification yourself. Your legal/verified details should be consistent with your accepted identification, tax, and payment records.
8. Search for beginner-friendly, properly scoped, **worldwide** projects, check client history and budget, and submit tailored applications. Most Upwork proposals use Connects, which may need to be purchased.

### Ready-to-paste Upwork overview

I'm a web developer focused on modern, mobile-friendly websites, practical web interfaces, and clear communication.

I can help with responsive landing pages, business websites, HTML/CSS/JavaScript improvements, website bug fixes, dashboard interfaces, and preparing front-end projects for deployment.

## 2. Fiverr – https://www.fiverr.com/

1. Create a standard account and verify your email. Choose a username carefully: **it cannot be changed later**.
2. On a **Windows PC / desktop browser**, open your profile menu and choose **Become a Seller**. Complete the onboarding truthfully. Fiverr's seller onboarding and Gig creation are desktop-only.
3. Use a display name that fits Fiverr's personal-name rules. List actual skills only, complete profile details and required verification.
4. Create your first Gig using the following information. Add a real work sample image that you created, agree realistic timing, and publish for review when all required fields are complete.

**Gig title:** I will build a responsive landing page using HTML CSS and JavaScript  
**Category:** Programming & Tech > the currently available website development category  
**Suggested search tags:** landing page, responsive website, html css, javascript, web developer

**Gig description:**

Need a clean, mobile-friendly landing page for your business or personal brand? I build responsive pages using HTML, CSS, and JavaScript with clear sections, smooth navigation, and layouts that work on desktop and mobile.

You will receive the agreed page design, source files, and simple handover instructions. Please message me before ordering if your site needs user registration, payment processing, databases, or third-party integrations, as these need a separate quote.

**Suggested starting packages:**
- Basic $40: 1 page, up to 3 sections, 1 revision, 3 days.
- Standard $90: 1 page, up to 5 sections, responsive menu, 2 revisions, 5 days.
- Premium $180: 1 page, up to 7 sections, basic interactive elements, handover/deployment guidance, 2 revisions, 7 days.

Check Fiverr's current category-specific pricing rules and only promise services/timelines you can fulfill.

## 3. What not to do

- Don't share a password, one-time login code, government ID, or financial account details with anyone helping with your profile.
- Don't misrepresent your location, identity, training, past paid work, or certifications.
- Don't accept requests to pay a client 'registration fees,' gift cards or crypto to start a job.
- Don't move Upwork/Fiverr discussions or payments off-platform in violation of platform rules.
